# MCP 2026-07-28 — manual for success

This is the **recommended** way to drive `nbcad-mcp`. Research the spec at
runtime if you can:
[MCP 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/).

The older `initialize` handshake (`2025-06-18` and earlier) remains a
**compatibility pathway**. It is not a recommendation. If you already sent
`initialize`, keep going — tools still work — and switch on this same process
when you can.

## Wire protocol

1. Call `server/discover`. Do not start with `initialize`.
2. On **every** later request, set `params._meta`:

```json
{
  "io.modelcontextprotocol/protocolVersion": "2026-07-28",
  "io.modelcontextprotocol/clientCapabilities": {},
  "io.modelcontextprotocol/clientInfo": { "name": "your-client", "version": "0" }
}
```

`clientInfo` is recommended. `clientCapabilities` is required on `2026-07-28`.
Unsupported versions return JSON-RPC `-32022` with a `supported` list; pick
`2026-07-28` and retry.

3. Then `tools/list` / `tools/call` as usual. Also `resources/list` /
   `resources/read` and `prompts/list` / `prompts/get`. No session handshake.

Main-surface reads (`nbcad://…`):

`document` · `project` · `scene` · `drawing` · `focus` · `workspace` ·
`sessions` · `sketch` · `sketches` · `profiles` · `visibility` ·
`appearances` · `materials` · `features`

Template: `nbcad://session/{session_id}`.

Main-surface recipes: `model_box`, `model_hole`, `model_solid`, `attach_ui`,
`print_3mf`, `model_print_tool`, `model_print_kit`, `import_step`, `export_step`, `drawing_read`,
`drawing_sheet`, `drawing_export`, `undo_history`, `invoke`.

Runtime upgrade from a compatibility `initialize`: call `server/discover` next,
then attach `_meta` to subsequent requests. Same process, same document.

## Modeling loop

One persistent headless document per `nbcad-mcp` process.

1. `sketch_begin` on a plane
2. `sketch_add_*` and constraints
3. `sketch_finish` → read `nbcad://profiles` (or `sketch_profiles`)
4. `solid_extrude` (or revolve / sweep / loft / rib)
5. Inspect with `nbcad://scene` / `nbcad://document` / `nbcad://features`
6. Use returned entity / body / face / edge ids in later calls

Soft disclosure is guidance, not a jail: out-of-focus tools stay callable.
Prefer `dynamic` focus; subagents can use `cad_list_all_tools`. Optional UI
co-link: `cad_list_sessions` → `cad_attach`. Live workspace:
`cad_set_workspace` / `nbcad://workspace`.

Drawings: `cad_drawing_create_sheet` → `cad_drawing_auto_layout` /
`cad_drawing_add_*` (view intent in the project model). Read with
`cad_drawing_document` / `nbcad://drawing`. Native HLR:
`cad_drawing_project_sheet`. Paper interchange:
`cad_drawing_export_dxf` / `cad_drawing_export_svg` /
`cad_drawing_export_profile_dxf` (recipe: `drawing_export`).

Print: prefer `solid_export_3mf` (recipe: `print_3mf`). CAD interchange:
`solid_export_step` / `solid_import_step` (recipes: `export_step`,
`import_step`). Application history: `cad_undo` / `cad_redo` (recipe:
`undo_history`). Raw engine: `cad_invoke` / `cad_drawing_command` (recipe:
`invoke`).

## Transport

Stdio is the editor path. For Kafka / MQTT / NATS, wrap the same JSON-RPC in
`nbcad-mcp-bus` (`NBCAD_MCP_TRANSPORT=bus-jsonl`). One worker process still
owns one document.
